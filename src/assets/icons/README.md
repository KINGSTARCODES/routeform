# Network, token and wallet marks

| File | Mark |
|---|---|
| usdc.svg, usdt.svg, eth.svg, near.svg | Tokens: USDC, USDT, ETH, NEAR |
| ethereum.svg, arbitrum.svg, optimism.svg, base.svg | Networks |
| metamask.svg, okx.svg, coinbase.svg, walletconnect.svg | Wallets |

Source: the open-source `web3icons` collection (MIT licensed, https://github.com/0xa3k5/web3icons),
"background" variants. These are vector redraws of each project's official logo, not files from the projects'
own brand kits.

The logos remain trademarks of their owners. They are used here only to identify the networks, tokens and
wallets in a non-affiliated interface concept. Before a public launch, compare them with each project's
official brand kit and follow its usage rules.

Not included: Bitget Wallet (no mark in the source set). The wallet list still shows a letter placeholder for it.
